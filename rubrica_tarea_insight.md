# Rúbrica: Tarea Insight

**Puntaje máximo: 20 puntos**

## 1. Clarity (Claridad) — /4 puntos

| Nivel | Descripción | Puntos |
|---|---|---:|
| Excelente | Visualizaciones muy claras y autoexplicativas; uso correcto de títulos, escalas, leyendas, narrativa visual, colores y espacio. | 4 |
| Bueno | Visualizaciones comprensibles, con etiquetas adecuadas y mensaje relativamente claro. | 3 |
| Básico | Visualizaciones legibles pero con carencias en títulos, leyendas o explicaciones. | 2 |
| Deficiente | Visualizaciones confusas, sin etiquetas ni explicaciones; difícil de interpretar. | 1 |

## 2. Analytical Insight (Perspectiva analítica) — /4 puntos

| Nivel | Descripción | Puntos |
|---|---|---:|
| Excelente | Revela insights profundos y novedosos; conecta hallazgos con el contexto (Spotify, artistas, géneros, etc.). | 4 |
| Bueno | Aporta algunos insights interesantes y relevantes para las tareas planteadas. | 3 |
| Básico | Presenta observaciones simples o evidentes. | 2 |
| Deficiente | No aporta insights relevantes; solo muestra datos sin análisis. | 1 |

## 3. Design Rationale (Justificación de diseño) — /4 puntos

| Nivel | Descripción | Puntos |
|---|---|---:|
| Excelente | Justificación sólida y bien argumentada: explica por qué cada técnica ayuda a responder las tareas analíticas y qué datos se seleccionaron. | 4 |
| Bueno | Justifica las técnicas usadas y relaciona parcialmente con las tareas analíticas. | 3 |
| Básico | Justificación débil o limitada a “porque era requerido”. | 2 |
| Deficiente | No hay justificación en la selección de técnicas. | 1 |

## 4. Technical Accuracy (Precisión técnica) — /4 puntos

| Nivel | Descripción | Puntos |
|---|---|---:|
| Excelente | Uso correcto y completo de todas las técnicas requeridas (RadViz, Star Coordinates, Parallel Coordinates y proyección) y buena ejecución. | 4 |
| Bueno | Técnicas bien implementadas; algunos detalles menores podrían mejorar. | 3 |
| Básico | Implementación funcional pero con errores en parámetros o librerías. | 2 |
| Deficiente | Uso incorrecto de técnicas (mal implementadas o incompletas). | 1 |

## 5. Tasks Coverage (Cobertura de tareas) — /4 puntos

| Nivel | Descripción | Puntos |
|---|---|---:|
| Excelente | Responde de forma clara y completa a las tareas analíticas, mostrando cómo las visualizaciones aportan respuestas significativas. | 4 |
| Bueno | Responde a las tareas, aunque con profundidad limitada. | 3 |
| Básico | Responde parcialmente (1 de 3) o de manera incompleta. | 2 |
| Deficiente | No responde a las 3 tareas mínimas. | 1 |

## Checklist de evaluación

- [ ] Las visualizaciones son claras, legibles y autoexplicativas.
- [ ] Los hallazgos están interpretados en el contexto de Spotify.
- [ ] Cada técnica tiene una justificación relacionada con una tarea analítica.
- [ ] Se implementaron RadViz, Star Coordinates, Parallel Coordinates y una proyección.
- [ ] Se respondieron las tres tareas analíticas mínimas.
- [ ] La entrega distingue entre mostrar datos y explicar insights.
